# Paper / IDA 功能对齐路线

Paper 按干净实现的方式复刻 IDA 的工作流和可观测能力，不复制 IDA 的专有代码或资源。功能按同一份分析数据库、GUI 和 MCP API 三条路径共享。

## 当前版本已接通

- PE/DLL/SYS 加载、x86/x64 指令索引、多核函数发现、`.pdata` 边界。
- Functions、IDA View-A、Hex View、Info、Xrefs/Properties。
- CFG 图、调用者/被调用者查询、导入/导出、Segments、Strings、Names、Bookmarks。
- 用户名称、重复注释、书签编辑；`<image>.paper.json` 侧车数据库自动恢复和退出自动保存。
- 十六进制搜索，支持 `?` 半字节/通配字节；所有核心查询可由 `paper_ai.exe` 的 MCP 工具调用。

## 后续对齐批次

1. **类型和函数签名**：函数原型、调用约定、参数/返回值、栈变量、结构体和枚举。
2. **反编译视图**：基于同一 CFG/指令索引的伪代码、微码和数据流证据。
3. **编辑能力**：安全的字节补丁、汇编/反汇编同步、补丁差异和撤销记录。
4. **扩展能力**：Python/插件 API、批处理任务、签名库和规则扫描接口。
5. **可选动态模块**：调试器、进程/线程/内存窗口；默认仍保持静态分析、不执行样本。

每个批次都会先落到 `paper_core` 和 MCP，再加入 ImGui 窗口，避免出现只显示按钮但没有可查询证据的空功能。
